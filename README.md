## 🚀 Featured Projects

### [ResearchHelp](https://github.com/Shrdha08/researchhelp) · RAG over research papers
`Python` `LangGraph` `Qdrant` `FastAPI` `PostgreSQL` `Docker`
- RAG pipeline with section-aware chunking, Qdrant vector search, and paper- and page-level citations
- Hybrid dense + BM25 retrieval with cross-encoder reranking: **Recall@5 0.48 → 0.66**, **MRR 0.30 → 0.45**
- LangGraph agent router for evidence Q&A vs. research-gap analysis that routed **all 52 test queries correctly**

### [Code Completion Assistant](https://github.com/Shrdha08/python-autocomplete)
`Python` `PyTorch` `Hugging Face` `CodeT5` `FastAPI`
- End-to-end NLP training pipeline on **CodeSearchNet**
- Compares a **Seq2Seq LSTM**, **CodeT5** and a **decoder-only Transformer** for code generation
- FastAPI endpoints return top-k completions for IDE-style autocomplete

### Peer-to-Peer Smart Agriculture System · Summer ELC Research, Thapar
`Python` `PyTorch` `ResNet` `YOLOv5`
- Image-based **pomegranate disease detection** module built with computer vision
- Benchmarked ResNet classification against YOLOv5 detection to choose the approach
